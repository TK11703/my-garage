Responsive menu

Wide screens (1200 px and up) show the full menu. From 768 px to 1199 px the menu shrinks to a rail of icons (names appear as tooltips and stay available to screen readers). Under 768 px the menu is hidden behind the hamburger button and slides over the page. These two frames load this page at those widths.

Tablet, 1000 px: icon rail
Phone, 390 px: hamburger

Light and dark

Both themes side by side, whichever one the page is showing. Content sits on a grey page color so cards, forms, and tables can be white (light) or a raised charcoal (dark).

Dark

Color swatches

Every color is a CSS variable in app.css. A data-bs-theme attribute on any element switches that subtree, which is how both themes show here at once. Text on the blue bar and the dark menu meets WCAG AA (4.5:1).

Components

Cards, tabs, and accordions follow the reference admin template: soft rounded white surfaces on a grey page, header with a muted subtitle, underline tabs, and bordered accordion blocks.
